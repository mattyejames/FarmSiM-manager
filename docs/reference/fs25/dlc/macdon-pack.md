## 1. WHAT IT ADDS

⭐ **A pure harvesting-attachment pack.** Official description: "MacDon brings you next level
harvesting performance, with five highlight machines... the M1240 Windrower, the DX140 & FD140
Headers, the PW8 pickup header, and the R216Sp disc header."

Four of the five items are **cutting/pickup attachments**; only the M1240 is a self-propelled
vehicle. There are no tractors, trailers, implements or buildings.

⚠️ **Naming discrepancy in the source:** the marketing text says "**DX140**" while the item list
says "**D 140 XL**". These appear to be the same machine described inconsistently on the same page.

## 3. WHAT EACH ONE IS FOR

| Machine | Job |
|---|---|
| **FD140 FlexDraper** | ⭐ Grain header — fits a combine, harvests the grain group (wheat, barley, oat, sorghum, canola, soybeans — see `crops-101.md` §2) |
| **PW 8** | ⭐ **Pickup header** — collects swathed material from the ground rather than cutting standing crop |
| **M1240** | ⭐ **Self-propelled windrower** — the carrier vehicle for the two windrower headers below |
| **D 140 XL** | Draper header for the windrower — cuts and lays material in a swath |
| **R216 SP** | Disc header for the windrower — for grass and forage |

⭐ **The M1240 + D 140 XL + R216 SP form one system:** a self-propelled windrower with
interchangeable cutting heads. The **R216 SP disc header** makes it a grass mower; the **D 140 XL**
makes it a grain/forage swather.

## 4. PLANNING NOTES

- ⭐ **At $4.99 this is one of the cheapest DLCs**, and its value depends entirely on whether you need the two functions it provides: wide-cut grain harvesting and windrowing.
- ⭐ **The FD140 at 12.5 m is a genuinely wide grain header.** For comparison, the New Holland FD250 Gold Edition reaches 15.2 m and the GERINGHOFF NEXAT headers 15.2 m — so the FD140 sits in the upper tier without needing a flagship combine.
- ⭐ **The windrower system is the real reason to buy it** if you make hay or silage. Per `animals-102.md` §3, the grass silage route needs **mower → windrower → baler → wrapper**, and a self-propelled windrower at 45 km/h with a disc header covers the first two steps in one machine.
- ⭐ **The PW 8 pickup header** pairs with that workflow — it collects the swath a windrower leaves, which is how forage harvesters gather grass for chaff.
- **Check header compatibility before buying.** Per `game-basics.md` §11, matching crop icons on both the harvester and the header indicate compatibility — the FD140 is a grain header, so it won't handle corn, sunflowers or specialist crops.
- ⚠️ **No update requirement is listed**, which is unusual. Verify it works with your game version before purchase.
